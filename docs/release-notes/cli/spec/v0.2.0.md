# cli/spec v0.2.0

A paths layout chosen independently of the operating system, command aliases and flag groups.
Every change is an addition: a tool that sets none of them behaves as in v0.1.0. It requires
`go.vipengele.org/commons` at v0.1.0, as before.

- **Paths layout** (ADR-0039). `paths.Layout` is `LayoutDefault`, the zero value that follows
  `Options.GOOS`, `LayoutXDG`, `LayoutDarwin` or `LayoutWindows`, with `Layout.String` and
  `Layout.Valid`; `Options.Layout` selects it. `LayoutXDG` honours the `XDG_*_HOME` variables on
  every operating system. `Resolve` rejects an unknown layout before the `Options.Home` and
  `<PREFIX>_HOME` shortcut. `GOOS` stays the target operating system for everything else, such as
  the mode change `Ensure` skips on Windows.
- **Command aliases.** `Command.Aliases` lists further words that select the command.
  `Command.Validate` rejects an alias that is not a lowercase slug and one that collides with the
  name or alias of a sibling.
- **Flag groups.** `Command.FlagGroups` lists `FlagGroup`s, each a `FlagGroupKind`, `MutuallyExclusive`
  or `RequiredTogether`, over the names of flags the command declares or inherits.
  `FlagGroupKind.String` names the kind. `Command.Validate` rejects a group with no kind, an
  unknown flag or too few flags. An adapter enforces the groups.
- **Dependencies.** `golang.org/x/mod` is raised from v0.42.0 to v0.43.0 and `golang.org/x/term`
  from v0.47.0 to v0.48.0; the indirect `golang.org/x/sys` goes from v0.49.0 to v0.50.0.

A consumer upgrades with `go get go.vipengele.org/cli/spec@v0.2.0`. Nothing has to change.
