# cli/spec v0.1.0

The first release of `cli/spec`, the framework-neutral description of a command-line tool that
`cli/core`, `update` and `daemon` share. It requires `go.vipengele.org/commons` v0.1.0.

- `spec`: a tool's `Identity`, and its commands as data. A `Command` carries its arguments
  (`ArgPolicy`), its typed flags (`BoolFlag`, `StringFlag`, `IntFlag`, read through
  `Get`/`IsSet` on an `Invocation`), shell completions (`CompleteChoices`, `CompleteFiles`,
  `CompleteDirs`, `CompleteFunc`), annotations such as `SkipUpdateCheck`, and its subcommands. An
  `Invocation` carries the `Env` (streams, working directory, environment) and the resolved
  `Output`: verbose, quiet, JSON, and colour per stream (`ColorAllowed`, `Styler`). `WriteJSON`
  writes one flat object whose first key is the integer `schema` (ADR-0007). The package performs
  no I/O; an adapter runs the tree with `Command.Validate`, `ArgPolicy.Check`, `NewInvocation` and
  `ExplicitFlags`.
- `paths`: resolves a tool's configuration, state, cache, data, log and runtime directories from
  its `Identity` (`Resolve`, `New`), creates them with `Dirs.Ensure`, and detects a container
  (`InContainer`, `InContainerFor`).
- `completioninstall`: installs a tool's completion script for zsh, bash, fish and PowerShell
  (`Install`, `Target`), and renders the same locations as a POSIX-sh or PowerShell fragment for an
  install script (`Snippet`, `PowerShellSnippet`).
- `table`: aligned text columns whose rows are also handed to JSON output.
- `terminal`: `Detect` reports which standard streams are attached to a terminal.
- `version`: `IsRelease` and `Newer` classify and order the versions a self-updating tool compares.
- `speccheck`: `AssertJSONKeys` pins the JSON keys of a type in a golden file for tests.

A consumer adds it with `go get go.vipengele.org/cli/spec@v0.1.0`.
