# cli/state v0.1.0

The first release of `cli/state`, which replaces files atomically and durably: a reader sees the
old content or the new in full, never a partial write, and the new content survives a crash once a
call returns. It requires no sibling project.

- `WriteFile(path, data, mode)` writes beside the destination, syncs, renames over it and syncs the
  directory; `Replace(tmp, final, mode)` does the same for a temporary file the caller already
  wrote. On Windows the directory sync is skipped, since NTFS journals the rename.
- `SaveJSON` and `SaveYAML` encode a value and write it with `WriteFile`.
- `LoadJSON` and `LoadYAML` decode a file and report a `LoadStatus`: `Missing`, `Loaded`,
  `Corrupt` (the content does not decode, and the error matches `ErrCorrupt`) or `Unreadable`.

The package creates no directory and takes no lock; a caller that needs exclusion combines it with
`go.vipengele.org/filelock`.

A consumer adds it with `go get go.vipengele.org/cli/state@v0.1.0`.
