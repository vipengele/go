# config v0.2.0

Collections in a schema, and an allow-list for a file layer. Every change is an addition: a schema
of scalars loads exactly as in v0.1.0. It requires no sibling project.

- **Maps and lists of structs.** A schema field may be a `map[string]T`, where `T` is a scalar,
  `time.Duration`, a slice of scalars, a struct or another map, or a slice of structs. A
  non-string map key, a pointer, or a slice of maps is still `ErrSchema`. An element struct reads
  its own `config` and `doc` tags; `Field.Kind()`, `Field.Merge()` and `Field.Elem()` describe a
  collection.
- **A merge strategy per field.** With no `merge` tag, a later layer replaces the collection whole,
  an empty one included. `merge:"<key>"` on a list of structs matches elements on that string
  field, replaces a match where it stands and appends new elements in the later layer's order.
  `merge:"keys"` on a map merges one level deep. A duplicate or empty merge key is an error at its
  file and line, or a `Load` error naming `defaults`.
- **Collections come from files only.** `Env` derives no variable for a collection or anything
  inside it, and `Flags` rejects a key that names one. A key inside an element that
  `RemovedKeys()` lists, such as `profiles.old`, is reported with its hint.
- **Reporting.** `Sources()` has one row per leaf, with paths such as `profiles[2].env["FOO"]`, and
  a `FieldError` on such a path carries the origin of what it names. A provider emits a collection
  as one `Entry` whose value is the new `Node` tree (`Node`, `NodeKind`, `NodeEntry`); a custom
  `Provider` that sets only scalars needs no change.
- **Seed** writes collections as elements, documented on the first, and an empty one as `[]` or
  `{}` after a commented-out example element.
- **`File(path).Allow(keys...)`** restricts the keys a file may set. A key outside the list, or
  outside a group the list names, is a problem at its line, `key "x" is not settable in <file>`,
  and is never dropped. A key naming a collection allows all of it. `Allow()` with no keys, or no
  call, allows every key.

A consumer upgrades with `go get go.vipengele.org/config@v0.2.0`. Nothing has to change: no
existing name changed, and a type `Load` refused before is now accepted.
