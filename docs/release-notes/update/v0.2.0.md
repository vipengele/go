# update v0.2.0

A paths layout for the default state directory. It requires `cli/spec` at v0.2.0, released with it,
and `cli/state`, `commons` and `filelock` at v0.1.0.

- **`Config.PathsLayout`** (ADR-0039) is the `paths.Layout` the default `StateDir` is resolved
  under, forwarded to `paths` when `StateDir` is empty. `GOOS` still picks the release asset, the
  `.exe` name and container detection, so a tool can keep the XDG layout on macOS and Windows and
  still download the archive of its own system. An unknown layout is a `Config` validation error.
- **Dependencies.** `cli/spec` is raised from v0.1.0 to v0.2.0, `golang.org/x/mod` from v0.42.0 to
  v0.43.0 and the indirect `golang.org/x/term` from v0.47.0 to v0.48.0.

A consumer upgrades with `go get go.vipengele.org/update@v0.2.0`. Nothing has to change: with
`PathsLayout` unset, the state directory is where v0.1.0 put it.
