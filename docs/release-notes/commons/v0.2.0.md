# commons v0.2.0

Adds a clock to `commons`, so that code which waits or defers a call can be tested without real
time passing. It still requires nothing beyond the standard library.

- `clock`: the `Clock` interface, with `Now`, `Sleep(ctx, d)`, which returns `ctx.Err()` when the
  context ends first, and `AfterFunc`. `System()` returns the clock of the operating system, and
  `IsSystem` reports whether a `Clock` is that clock.
- `clock/clocktest`: a manual clock for tests. `New` returns one reading a chosen time, `Advance`
  moves it forward and fires every sleep and deferred call that falls due, and `Pending` counts
  the ones still waiting. An `AfterFunc` call runs synchronously inside the `Advance` that reaches
  its deadline.

A consumer adds it with `go get go.vipengele.org/commons@v0.2.0`.
