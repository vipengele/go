# commons v0.1.0

The first release of `commons`, the generic building blocks every library of the platform may
require. It requires nothing beyond the standard library.

- `validate`: field checks that return aggregated, field-named errors, with the sentinel errors
  `ErrEmpty` and `ErrInvalid`.
- `envvar`: derives environment-variable names of the form `<PREFIX>_<SUFFIX>`.

A consumer adds it with `go get go.vipengele.org/commons@v0.1.0`.
